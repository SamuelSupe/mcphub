什么时候需要个人账号

一些服务使用你的上游账号调用，例如个人 Token 或浏览器授权账号。管理员配置共享账号的服务可能无需此步骤。向导或 doctor 提示未连接、过期或需重连时，到个人授权中心处理。

连接账号

  1. 打开公司 MCPHub 的 /client-auth/ 并登录。
  2. 在「已连接账号」找到目标服务，点击「连接账号」。
  3. 浏览器授权方式：选择自己的上游账号并确认权限。Token 方式：填写个人 Token，可选填备注和到期时间，点击「验证并连接」。
  4. 确认显示「已连接」；「查看授权详情」显示账号、权限、有效期和能否自动续期。
  5. 回客户端继续，必要时运行对应入口的 doctor。
在账号连接页填写上游凭证客户端配置无需个人 Token 或凭证存储路径。账号可供你在该服务的多个已授权客户端使用，每个入口仍遵守自己的范围。

账号状态

状态下一步
尚未连接连接账号。
已连接继续检查客户端授权和业务权限。
需要重新连接重新连接，确认凭证及上游权限。
暂时无法验证重试；持续失败请管理员检查账号服务。
服务已停用或访问权限已移除联系管理员确认服务和访问资格。

更换或重新连接

「重新连接」会替换当前上游账号，使原客户端授权失效，并可能取消执行中的请求和订阅。完成后重新运行 client authorize 或向导，再重启连接。

首次连接可满足已有授权；更换或断开后再连接则需重新授权。已完成的业务操作不会撤销。

断开账号

点击「断开连接」并确认，相关客户端授权失效。需要撤销上游授予 MCPHub 的权限时，按上游服务的授权管理流程操作。退出网页或本机 logout 不替代断开账号。

连接未完成

取消或连接失败时原有连接保持不变。链接过期则重新点击「连接账号」；Token 被拒绝时检查账号、有效期与业务权限；配置在过程中改变时刷新门户后重试。
