第一次部署

先完成一条只读调用

部署网关，接入一个只读服务，显式发布工具，配置测试用户，再完成登录和客户端授权。验证成功后逐步开放写操作。

推荐部署顺序

  1. 安装网关，选择本地或远程管理，保留数据库和密钥。
  2. 配置 HTTPS 与身份服务，分别验证管理员和普通用户登录。
  3. 接入服务，在工具权限中显式发布已审核的只读工具。
  4. 授予用户权限，启用客户端授权，交付用户指南。
  5. 需要个人业务账号时配置Vault；需要写工具时配置审批。
  6. 实际验证一次普通用户调用、撤销和所需审批，再按运行维护安排健康检查、备份与诊断。

生产部署保持单实例MCPHub v2.2.0 支持 SQLite 或单实例 PostgreSQL。共用 PostgreSQL 不会让多个网关自动同步运行时配置。管理员权限也不会自动授予业务工具或写审批权限。
