先完成 MCPHub 向导

运行 接入向导，选择通用 JSON。记下实际 command、args、env 和入口 ID，下列值均为示例。

添加本机连接器

通过 Claude Code CLI 添加 stdio 连接，此例使用个人范围：

claude mcp add --transport stdio --scope user work-projects --env MCPHUB_HOME=/Users/you/.mcphub -- /absolute/path/to/mcpbridge connect --profile work --client ci_example

-- 后是连接器及其参数。Windows 使用 exe 的实际路径，带空格的路径加引号。

也可将生成的 mcpServers 条目合并到项目根目录 .mcp.json。个人路径与入口 ID 不适合作为团队共用配置；每人应建立自己的入口。

检查连接

claude mcp list
claude mcp get work-projects

进入 Claude Code 后使用 /mcp 查看状态，项目级服务器可能需先确认信任和启用。配置写入成功不等于连接成功，继续运行 MCPHub doctor 检查实际入口。

停用或移除

在 /mcp 管理客户端侧连接，或使用 claude mcp remove work-projects --scope user 移除本例配置。要阻止该入口继续访问 MCPHub，另到个人授权中心撤销授权。

命令格式、配置范围和服务器状态见 Claude Code 官方 MCP 文档。
