Verify the download

Download SHA256SUMS for the same version. Calculate the archive's SHA-256 and compare it exactly with the entry for that filename before extracting. Adjust the filenames below for your CPU.

macOS Apple Silicon

shasum -a 256 mcpbridge_v2.2.2_darwin_arm64.tar.gz
tar -xzf mcpbridge_v2.2.2_darwin_arm64.tar.gz

Linux amd64

sha256sum mcpbridge_v2.2.2_linux_amd64.tar.gz
tar -xzf mcpbridge_v2.2.2_linux_amd64.tar.gz

Windows PowerShell x64

Get-FileHash .\mcpbridge_v2.2.2_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\mcpbridge_v2.2.2_windows_amd64.zip -DestinationPath .\mcpbridge

Make the connector available to your client

Keep the executable in a stable private tools directory and add it to PATH, or use its absolute path. The executable is mcpbridge on macOS/Linux and mcpbridge.exe on Windows.

On macOS/Linux, after extracting in the previous step, run:

mkdir -p "$HOME/.local/bin"
install -m 755 ./mcpbridge "$HOME/.local/bin/mcpbridge"
export PATH="$HOME/.local/bin:$PATH"
mcpbridge --version
mcpbridge setup --help

This PATH setting applies to the current terminal. For later runs, use "$HOME/.local/bin/mcpbridge" directly or add the directory to your shell's PATH. Go installs into go env GOBIN, or $(go env GOPATH)/bin when GOBIN is empty; add that directory to PATH too.

mcpbridge --version displays mcpbridge 2.2.2 (client). If the command displays setup options, your terminal can run the connector. On Windows without PATH configuration, use .\mcpbridge\mcpbridge.exe setup --help. Graphical clients may have a different PATH, so preserve the absolute path generated by setup. If your operating system blocks execution, give the exact message to IT or your administrator.

Downloads and release notes are in the v2.2.2 release. With Go 1.26 installed, you can use go install github.com/SamuelSupe/mcphub/v2/cmd/mcpbridge@v2.2.2.

Service prerequisites for a fresh deployment

Use the matching v2.2.2 gateway and MCPBridge. The administrator first adds backends, tests connections and publishes tools. Setup also needs the user portal and client authorization. Obtain the actual gateway URL, client ID and required scopes before proceeding.
