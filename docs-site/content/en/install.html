On macOS, check the chip in About This Mac. On Windows, check the system type in Settings → System → About. On Linux, run uname -m: x86_64 means amd64, and aarch64 means arm64.

Verify the download

Download SHA256SUMS for the same version. Calculate the archive's SHA-256 and compare it exactly with the entry for that filename before extracting. Adjust the filenames below for your CPU.

macOS Apple Silicon

shasum -a 256 mcphub-cli_v2.2.1_darwin_arm64.tar.gz
tar -xzf mcphub-cli_v2.2.1_darwin_arm64.tar.gz

Linux amd64

sha256sum mcphub-cli_v2.2.1_linux_amd64.tar.gz
tar -xzf mcphub-cli_v2.2.1_linux_amd64.tar.gz

Windows PowerShell x64

Get-FileHash .\mcphub-cli_v2.2.1_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\mcphub-cli_v2.2.1_windows_amd64.zip -DestinationPath .\mcphub-cli

Make the connector available to your client

Keep the executable in a stable private tools directory and add it to PATH, or use its absolute path. The executable is mcphub-cli on macOS/Linux and mcphub-cli.exe on Windows.

On macOS/Linux, after extracting in the previous step, run:

mkdir -p "$HOME/.local/bin"
install -m 755 ./mcphub-cli "$HOME/.local/bin/mcphub-cli"
export PATH="$HOME/.local/bin:$PATH"
mcphub-cli setup --help

This PATH setting applies to the current terminal. For later runs, use "$HOME/.local/bin/mcphub-cli" directly or add the directory to your shell's PATH. Go installs into go env GOBIN, or $(go env GOPATH)/bin when GOBIN is empty; add that directory to PATH too.

If the command displays setup options, your terminal can run the connector. On Windows without PATH configuration, use .\mcphub-cli\mcphub-cli.exe setup --help. Graphical clients may have a different PATH, so preserve the absolute path generated by setup. If your operating system blocks execution, give the exact message to IT or your administrator.

Upgrade an existing connector

  1. Download the version recommended by your administrator and verify its checksum.
  2. Quit clients using the connector. If the broker is running, use mcphub-cli broker stop.
  3. Replace the executable at its existing path. Keep your local .mcphub directory; existing profiles do not need migration.
  4. Restart your client and run doctor for the actual entry. If the executable moved, update command in the configuration.

Stopping the broker keeps remote grants. Upgrading does not extend expired grants.
