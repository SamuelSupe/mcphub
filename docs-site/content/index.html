MCPHub 让你在 Codex、Claude Code、VS Code 等 AI 客户端中使用公司已开放的工具。你通过公司账号登录，为每个客户端选择工具和数据范围；需要写入时，再对具体操作进行审批。

第一次使用

从一次成功的连接开始

准备公司接入地址，安装连接器，运行向导，再把生成的配置加入 AI 客户端。

完成第一次接入 →

按你的任务查找

01 · 接入配置我的 AI 客户端 →

选择 Codex、Claude Code、VS Code 或其他支持 MCP 的客户端。

 02 · 账号连接个人服务账号 →

在个人授权中心连接、重连或断开上游服务账号。

 03 · 审批完成一次写操作 →

理解待审批状态，确认具体参数，并从原客户端继续执行。

 04 · 排障解决连接和权限问题 →

从工具不可见、授权过期、401、403 或 503 开始定位。

你会用到的三个入口

入口用来做什么
AI 客户端发现工具、发起调用、查询和恢复审批。
本机连接器 mcphub-cli完成公司登录、生成客户端配置、检查连接。
个人授权中心在公司的 MCPHub 域名下访问 /client-auth/，管理个人账号和客户端授权。
先确认公司已为你开通访问能够使用公司 SSO 登录，并不代表已经拥有服务或工具权限。首次登录若提示待授权，请联系 MCPHub 管理员。

这套文档适合谁

适合在自己的电脑上使用公司工具的员工和审批人。服务器部署、身份服务、工具发布及运行维护由管理员负责，另见 管理员手册。

文档以 MCPHub v2.2.0 为基准。公司部署可能只开放部分服务；工具名称、权限和审批要求以你的授权页面为准。文中的 hub.example.com、ci_example 和服务名都是示例，请替换为实际值。
