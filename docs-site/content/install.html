选择正确的下载包

最终用户需要安装 mcphub-cli。版本为 v2.2.0 的下载文件如下；服务器程序由管理员安装。

电脑类型下载
macOS · Apple Silicon（M 系列）darwin_arm64.tar.gz
macOS · Inteldarwin_amd64.tar.gz
Linux · Intel / AMD 64 位linux_amd64.tar.gz
Linux · ARM64linux_arm64.tar.gz
Windows 10+ · Intel / AMD x64windows_amd64.zip
Windows 10+ · ARM64windows_arm64.zip

macOS 在「关于本机」查看芯片；Windows 在「设置 → 系统 → 关于」查看系统类型；Linux 使用 uname -m。x86_64 对应 amd64，aarch64 对应 arm64。

核对下载文件

下载同版本的 SHA256SUMS。计算下载包的 SHA-256，和文件中同名条目的值逐字核对，一致后再解压。下列命令的文件名需按架构替换。

macOS Apple Silicon

shasum -a 256 mcphub-cli_v2.2.0_darwin_arm64.tar.gz
tar -xzf mcphub-cli_v2.2.0_darwin_arm64.tar.gz

Linux amd64

sha256sum mcphub-cli_v2.2.0_linux_amd64.tar.gz
tar -xzf mcphub-cli_v2.2.0_linux_amd64.tar.gz

Windows PowerShell x64

Get-FileHash .\mcphub-cli_v2.2.0_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\mcphub-cli_v2.2.0_windows_amd64.zip -DestinationPath .\mcphub-cli

让电脑和客户端找到连接器

将可执行文件放在固定的私有工具目录并加入 PATH，也可始终使用绝对路径。macOS/Linux 文件名为 mcphub-cli，Windows 为 mcphub-cli.exe。

mcphub-cli setup --help

看到接入参数说明，表示当前终端可以运行连接器。未添加 PATH 的 Windows 用户可运行 .\mcphub-cli\mcphub-cli.exe setup --help。图形客户端的 PATH 可能不同，因此保留向导生成的绝对路径最稳妥。系统阻止执行时，把具体提示交给 IT 或管理员处理。

升级已有连接器

  1. 下载管理员推荐的版本，核对校验值。
  2. 退出使用连接器的客户端；Broker 正在运行时，可执行 mcphub-cli broker stop。
  3. 替换原路径的可执行文件。保留本机 .mcphub 目录，已有 profile 无需迁移。
  4. 重新启动客户端，运行 doctor 检查实际入口。文件位置改变时，更新配置中的 command。

停止 Broker 保留远端授权；升级不会自动延长已到期的授权。
