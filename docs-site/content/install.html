客户端现名为 MCPBridge。 从 v2.2.2 起，用户安装 mcpbridge 连接 Agent；管理员按服务端指南安装 mcphub。serve、validate 只属于服务端程序。

选择正确的下载包

最终用户需要安装 mcpbridge。版本为 v2.2.2 的下载文件如下；服务器程序由管理员安装。

电脑类型下载
macOS · Apple Silicon（M 系列）darwin_arm64.tar.gz
macOS · Inteldarwin_amd64.tar.gz
Linux · Intel / AMD 64 位linux_amd64.tar.gz
Linux · ARM64linux_arm64.tar.gz
Windows 10+ · Intel / AMD x64windows_amd64.zip
Windows 10+ · ARM64windows_arm64.zip

macOS 在「关于本机」查看芯片；Windows 在「设置 → 系统 → 关于」查看系统类型；Linux 使用 uname -m。x86_64 对应 amd64，aarch64 对应 arm64。

核对下载文件

下载同版本的 SHA256SUMS。计算下载包的 SHA-256，和文件中同名条目的值逐字核对，一致后再解压。下列命令的文件名需按架构替换。

macOS Apple Silicon

shasum -a 256 mcpbridge_v2.2.2_darwin_arm64.tar.gz
tar -xzf mcpbridge_v2.2.2_darwin_arm64.tar.gz

Linux amd64

sha256sum mcpbridge_v2.2.2_linux_amd64.tar.gz
tar -xzf mcpbridge_v2.2.2_linux_amd64.tar.gz

Windows PowerShell x64

Get-FileHash .\mcpbridge_v2.2.2_windows_amd64.zip -Algorithm SHA256
Expand-Archive .\mcpbridge_v2.2.2_windows_amd64.zip -DestinationPath .\mcpbridge

让电脑和客户端找到连接器

将可执行文件放在固定的私有工具目录并加入 PATH，也可始终使用绝对路径。macOS/Linux 文件名为 mcpbridge，Windows 为 mcpbridge.exe。

macOS/Linux 在上一步解压后执行：

mkdir -p "$HOME/.local/bin"
install -m 755 ./mcpbridge "$HOME/.local/bin/mcpbridge"
export PATH="$HOME/.local/bin:$PATH"
mcpbridge --version
mcpbridge setup --help

此 PATH 设置用于当前终端；后续可运行 "$HOME/.local/bin/mcpbridge"，或将该目录加入 shell 的 PATH。Go 安装路径是 go env GOBIN，为空时是 $(go env GOPATH)/bin，也需加入 PATH。

mcpbridge --version 应显示 mcpbridge 2.2.2 (client)。看到接入参数说明，表示当前终端可以运行连接器。未添加 PATH 的 Windows 用户可运行 .\mcpbridge\mcpbridge.exe setup --help。图形客户端的 PATH 可能不同，因此保留向导生成的绝对路径最稳妥。系统阻止执行时，把具体提示交给 IT 或管理员处理。

发布文件及版本说明见 v2.2.2 Release。已安装 Go 1.26 的用户可执行 go install github.com/SamuelSupe/mcphub/v2/cmd/mcpbridge@v2.2.2。

新部署的服务准备条件

使用匹配的 v2.2.2 网关和 MCPBridge。管理员先添加后端、测试连接并发布工具；运行 setup 还需要用户门户和客户端授权。取得实际网关地址、客户端 ID 和所需 scope 后继续。
