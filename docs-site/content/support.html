什么时候联系管理员

账号待授权、服务未开放、权限调整、账号服务异常、审批人配置和持续 503 需要管理员处理。先按 症状排查。

生成诊断

mcphub-cli doctor --profile work --client ci_example --json --timeout 30s > mcphub-diagnostics.json

使用实际入口。报告不包含 Token 或进程通信凭证。阻塞问题以非零状态退出，但保留已经输出的报告。

提供定位线索

  • 发生时间、时区和频率。
  • 系统、架构、连接器版本及 AI 客户端版本。
  • MCPHub 地址、profile、入口 ID、服务、工具。
  • 具体错误、诊断、请求 ID 或审批 ID。
  • 期望和实际结果；最近是否重授权、更换账号或升级。

写入明确说明尚未执行、已被接受或结果不确定，先核实再重试。

提交前检查

不要发送凭证目录、登录 Token、个人 Token、完整授权 URL 或正在使用的配对码。业务标识和参数按公司要求处理，管理员可用时间与请求 ID 查询。

产品问题反馈

公司接入及业务问题先联系内部管理员。确认产品缺陷后，由管理员整理无秘密复现信息提交 项目问题。安全问题按 安全报告说明 处理。
