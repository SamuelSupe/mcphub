生成专用配置

运行 接入向导，选 2 · VS Code servers JSON。生成配置使用顶层 servers 对象和 type: stdio。

选择保存位置

命令面板运行 MCP: Open User Configuration 配置个人范围；当前项目使用 .vscode/mcp.json。将实际生成条目合并到原有 servers：

{
  "servers": {
    "work-projects": {
      "type": "stdio",
      "command": "/absolute/path/to/mcpbridge",
      "args": ["connect", "--profile", "work", "--client", "ci_example"],
      "env": { "MCPHUB_HOME": "/Users/you/.mcphub" }
    }
  }
}

替换示例值，保留已有其他服务器。

启动并检查

命令面板运行 MCP: List Servers，选择服务器启动或重新启动，按要求确认信任。检查工具目录；失败时查看服务器输出，再运行对应入口的 doctor。

SSH 与 Dev Container

执行位置取决于 VS Code 配置范围和远程环境。连接器、MCPHUB_HOME、登录及授权必须属于实际执行环境；本机配置不能直接拷入容器，见 多服务与多环境。

官方参考

配置位置和管理方式见 VS Code 官方 MCP 文档。
