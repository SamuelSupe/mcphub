MCPHub 连接此服务时使用的凭证。

Header 名称凭证值

凭证加密保存；编辑时留空保留原值。

03

客户端访问权限

控制哪些客户端可以通过 MCPHub 调用此后端。

留空允许所有已认证客户端访问；填写多个时必须全部满足。

工具级规则可选

匹配规则全部生效。effect 填 read 或 write；未分类也需要审批，write 优先。资源参数使用 JSON Pointer 和精确允许值。

限流策略默认不限流

所有用户共享此 endpoint 的额度；HTTP 工具组内的工具共用额度。超限请求立即拒绝，不排队。

高级连接设置超时、关键后端、本地 HTTP
